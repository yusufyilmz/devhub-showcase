# MyDevStudio guides

## When to read

Read this when the change is about the portfolio studio: accounts, publication, sections, CV import, premium access, billing, or the assistant. Open the matching guide below before changing that behavior. Setup commands stay in the [repository README](../../README.md). Click-by-click checks stay in the [manual testing index](../testing/manual/index.md).
