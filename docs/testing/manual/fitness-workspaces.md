# Private Fitness workspaces and shared UI

**Scope/status.** Each confirmed account can use its own Fitness workspace. Existing accounts retain their records. Public preview uses fictional activities. The daily dashboard, settings, and loading and error states use shared UI components. The existing workspace schema supports this release.

**Prerequisites.** Use two confirmed disposable Fitness accounts and two browser profiles. Use fictional logs. For Google self-service signup, enable Google and new-user signup in the Fitness Supabase project and allow the deployment's callback URL. Email/password testing requires provisioned accounts. Set `APP_URL` to the tested origin. Local examples use port 3002. For deployed checks, replace the origin with the Fitness preview or production host.
