# Portfolio blocks and Sections settings

The Sections view lives in the authenticated portfolio editor. Dashboard is an addable custom section with owner-entered metrics. The newsletter links to the subscription page configured by the owner.

Use Storybook on port 6006 for the shared components and the app fixture server on ports 3100 and 3101 for the editor. Use the disposable `desktop-custom-owner` fixture account. See the [manual testing index](index.md#before-you-start) for setup.
