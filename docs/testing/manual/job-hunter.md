# Job Hunter manual testing

**Scope/status:** Local MVP. Verify the configured provider, scheduled worker and browser delivery in a disposable preview before rollout.

**Prerequisites:** Apply the Job Hunter migration to a disposable Supabase database. Use two confirmed test accounts and add a fictional CV with a few job-relevant achievements to the first account. Configure `ADZUNA_APP_ID`, `ADZUNA_APP_KEY`, and a `JOOBLE_COUNTRY_KEYS` JSON object with an authorized key for each tested country (for example, `{"gb":"…"}`). Adzuna commercial or ongoing use requires the appropriate provider agreement. Configure the app's existing OpenAI and rate-limit settings. For push, set `JOB_PUSH_SUBJECT`, `JOB_PUSH_PUBLIC_KEY`, and `JOB_PUSH_PRIVATE_KEY` and use a secure browser. For unattended discovery, configure a dedicated preview `CRON_SECRET` of at least 32 characters, then follow the Vault and Cron instructions in [job-hunter-cron.sql](../../../supabase/setup/job-hunter-cron.sql). Enter secrets through the environment or Vault.

Use [shared setup and result rules](index.md#before-you-start). Replace the sample hostname with the deployed preview or local app origin. Each external test scan consumes provider requests and can use the configured AI model.

**Manual result:** Not run against live providers or a deployed preview.

Provider APIs offer market-specific coverage and abbreviated vacancy data. Location and title queries run against provider search. Filters that require specific evidence may exclude listings with missing metadata. Jooble update timestamps are displayed as updates. A posted-date filter requires an actual posting date.

The worker makes one Adzuna request and one Jooble request per eligible scan, subject to each configured daily budget. Defaults are 100 per day across Adzuna markets and 100 per Jooble market. Adjust `ADZUNA_DAILY_LIMIT` and `JOOBLE_DAILY_LIMIT` to match the authorized accounts. The worker scores up to five new or changed matches per scan. Discover displays the most recent 250 matches and keeps saved jobs available separately.
