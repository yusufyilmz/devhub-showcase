# Live Section Preview

**Scope and status** — Shared section examples on home, in managed creation, and in the portfolio editor.

**Prerequisites** — Use the local Studio fixture server on port 3100 and disposable fixture accounts. See [shared setup](index.md#before-you-start). Use desktop and mobile widths and switch theme modes with Appearance controls.

| Step | Clickable URL                                                        | Route path                    | Action                                                                                                                                                                                  | Expected result                                                                                                                             | Actual result                                                                                                        |
| ---- | -------------------------------------------------------------------- | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 1    | [Home](http://localhost:3100/#section-library)                       | `/`                           | Switch the featured picker to **Timeline** and **FAQ**. In the catalog, search for **Gallery Grid**, open its card and a tile, then search for **YouTube** and open its card.           | The featured picker and catalog use live sections. The gallery lightbox opens and the YouTube provider stays disabled.                      | Desktop light and mobile dark passed.                                                                                |
