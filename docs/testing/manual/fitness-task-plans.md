# Fitness task plan cards

**Scope and prerequisites.** Use a disposable confirmed My Fitness Studio account with at least two fictional plans and a subtask. Open the signed-out demo to check read-only behavior. The links below are production routes to test after deployment. Use the preview origin to test the branch earlier.

| Step | Clickable URL                                                       | Route path            | Action                                                                                                 | Expected result                                                                                                  | Actual result / evidence                                      |
| ---- | ------------------------------------------------------------------- | --------------------- | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| 1    | [Tasks](https://myfitnessstudio.vercel.app/?view=Tasks)             | `/?view=Tasks`        | Open Tasks on desktop. Hover a plan and move the pointer away.                                         | Each card previews the plan name, type and subtask count. Subtasks and controls reveal smoothly in about 650 ms. | Local Chromium fixture. Hosted check pending.                 |
| 2    | [Tasks](https://myfitnessstudio.vercel.app/?view=Tasks)             | `/?view=Tasks`        | Tab to a card, inspect its controls, then press Escape. Reduced motion reveals details immediately.                  | Local focus and reduced-motion fixture. Hosted check pending. |
