# Fitness task plans — manual testing

**Scope/status:** Implemented for the My Fitness Studio Tasks workspace. The plan selector, action icons, summary, task details, and pagination share one full-width card. Each drill-down shows the selected task and its immediate children.

**Prerequisites:** Use a matching preview or build and a disposable signed-in fitness account. Create at least two fictional plans. Include a workout with a superset, exercise and set in one plan. Use the linked production routes once the change ships, or substitute your preview hostname while keeping the exact path.

**Manual result:** Local desktop and mobile checks passed on November 6, 2026 using fictional fixtures. Hosted checks are pending.
