# Fitness task plan cards

**Scope and prerequisites.** Use a disposable confirmed My Fitness Studio account with at least two fictional plans and a subtask. Open the signed-out demo to check read-only behavior. The links below are production routes to test after deployment. Use the preview origin to test the branch earlier.
