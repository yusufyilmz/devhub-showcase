# Fitness assistant

**Scope/status:** The signed-in workspace header opens a full-page assistant at `/?view=Assistant`. AI modes generate drafts for review. Shopping lists use the existing weekly planner, and immediate notifications use the current device’s notification permission.

**Prerequisites:** Use the branch preview, a disposable owner with a fictional gym plan, workout, and meal ingredients. For AI modes use configured preview `OPENAI_API_KEY`, `REDIS_URL`, and `REDIS_TOKEN`. Set the preview's allowed app origin. Use stubs to avoid provider usage. Grant browser notification permission on the test device for the send step. The production links identify the routes after rollout. Substitute the preview hostname for review.

**Manual result:** Hosted verification pending.
