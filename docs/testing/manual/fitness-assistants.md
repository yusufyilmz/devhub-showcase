# Fitness plan and reminder assistants

**Scope/status:** Implemented behind optional server-side provider configuration. Generation returns a draft. The existing task editor owns review and saving.

**Prerequisites:** Use the branch preview, a disposable owner with a fictional plan and at least one workout, and configured preview `OPENAI_API_KEY`, `REDIS_URL`, and `REDIS_TOKEN`. Set the preview's allowed app origin. Use stubs to avoid provider usage. The production links identify the routes after rollout. Substitute the preview hostname for review.

**Manual result:** Hosted verification pending.
