# Assistant companions

**Scope and status.** MyDevStudio and My Fitness Studio use animated
characters to launch their existing assistant chats. Studio can show a draft
save and Fitness can show a due activity reminder. An in-app reminder uses
the workspace reminders setting. Device notifications still require browser
permission.

**Prerequisites.** Run the local apps with Playwright fixtures and start
Storybook on port 6006. Use a disposable confirmed Studio owner. For a Fitness
reminder, use an editable workspace with reminders enabled and an activity
scheduled for the current minute in the workspace time zone.
