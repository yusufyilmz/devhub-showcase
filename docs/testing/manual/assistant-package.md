# Shared assistant package — manual testing

**Scope/status:** Shared assistant/chat/companion, Fitness proposals, portfolio/studio workspaces, examples, management UI and CV rendering are consolidated in `@shared/assistant`. The apps retain session, cookie, environment, routing and authenticated transport adapters. Primitive UI/style ownership remains `@shared/ui`.

**Prerequisites:** Node 24.15+ below 25, pnpm 11, installed workspace dependencies, disposable fictional profiles and Fitness workspace. For browser checks use the matching local/preview build. Providers must be stubbed or configured with approved test credentials. Do not publish or transfer real records. No provider, production database or deployment checks are implied by local test results.

**Manual result:** Not run. Record build/commit, tester/date and evidence before marking a browser step complete. Follow the [shared setup rules](index.md#before-you-start).

## Automated checks

Run `pnpm typecheck`, `pnpm test`, `pnpm check:exports`, `pnpm build:studio` and `pnpm build:fitness`. Regression suites cover streaming chunks/interruption, injected device callbacks, companion progress transport, owner isolation, publication, quotas, private drafts and CV layouts. Fixtures and mocks do not establish provider or deployed verification. See [package exports and ownership](../../../packages/assistant/CATALOG.md).

Local automated evidence on 2026-11-07 in the primary checkout: root/workspace type checking passed all 14 tasks; 664 unit tests passed across 190 files; both Studio and Fitness production builds passed. Package export validation passed. Regression tests include split streaming events, interrupted answers, app-supplied device notification callbacks and companion progress transport. These results do not mark the browser checklist above as manually verified and do not verify paid providers or deployed behavior.

A local browser smoke check of the built apps also passed: the fictional Studio example at `http://localhost:3161/p/examples/avery-morgan` rendered successfully, and the read-only Fitness preview at `http://localhost:3162/preview` opened its Week tab. Both returned HTTP 200 with no browser runtime errors or failed local requests. The temporary verification servers were stopped afterward. Signed-in/private mutation flows and paid providers were not exercised by this smoke check.
