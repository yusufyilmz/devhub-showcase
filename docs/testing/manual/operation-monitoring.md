Use [shared setup](index.md#before-you-start). Replace `test-owner` and hostname with the disposable preview. Editor tabs share the editor route. Collector configuration is server-only; use a receiver you control and verify the HMAC before processing.

## Evidence and boundaries

Tests: `packages/utils/src/monitoring.test.ts`, `apps/my-dev-studio/features/platform/operation-monitoring.test.ts`, existing billing/assistant/stream route suites, and paid chat component suite. `pnpm check`, `pnpm test` and the app build results are recorded in the PR.

This does not install Sentry, create alert rules, send human notifications or instrument database-native cron runs. Inspect native cron history separately. Log delivery is best effort, not a durable queue; collector failure never retries a payment or publication. User cancellation cannot undo an already reserved AI attempt. CI/local fixtures are not proof of hosted delivery.

Local verification: `pnpm check` passed; full unit suites passed **543 tests** (510 shared/app and 33 fitness); final focused suites passed 24 tests; production app build passed; desktop/mobile Playwright passed **12 cases** across billing, owner AI, public chat and operation monitoring. The real local billing route returned a fresh UUID reference without echoing the fictional request payload. No production migration, real provider request or hosted alert was used.
