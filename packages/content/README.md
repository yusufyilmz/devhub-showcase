# Shared content

`src/profile.ts` supplies the bundled public fallback. Published profile storage is authoritative when configured; named private or missing profiles must never borrow another person's fallback data. `src/site-copy` contains labels and metadata copy.

PDFs are generated by `@shared/cv` from the permitted saved profile. There is no committed `apps/web/public/cv.pdf` to update. See [features](../../docs/features.md) and [architecture](../../docs/architecture.md).
