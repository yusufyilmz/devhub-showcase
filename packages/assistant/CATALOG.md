# Assistant catalog

> **AI lookup guide:** From the repository root, run `pnpm --silent lookup catalog "portfolio" --package @shared/assistant --limit 2` to read relevant excerpts. Verify an exact export with `pnpm --silent lookup symbol '<ExportName>' --package @shared/assistant`. Follow `hasMore` with `--cursor`; use `--max-tokens` to control output size. Excerpts support discovery; read required instructions and source contracts. See the [AI quick start](../../.agents/README.md) and [full CLI usage](../../tools/cli/README.md#token-bounded-repository-lookup).

Focused writing and section feedback run through PortfolioEditModel. The focused-assistant helper sends selected source text only and reconstructs validated proposals. See docs/features/assistant-guidance.md for review, configuration and publication snapshot behavior.

Provider configuration and optional text streaming live in
src/chat/services/provider.ts (AssistantService). Workflows own task context and
validation; use the service for provider access, not a second business workflow.
See docs/features/assistant-configuration.md for saved agents and external prompts.
Text budgets are checked in src/chat/services/token-budget.ts before generation. See
docs/features/assistant-rollout.md for the rollout and copy-ready prompts.

Portfolio and editing assistants for `@shared/assistant`. Workflows call a provider. They do not authorize a user or write a profile.

HomeChatLauncher in src/chat/components/chat-launcher/chat-launcher.tsx composes the shared
ChatComposer and opens the authenticated Studio assistant below the capabilities strip.
ChatComposer also accepts optional controls and a message length limit for Fitness.
ChatComposer and StudioChatScreen from @shared/ui/display provide the compact icon
composer and centered assistant thread with starter prompts. Visitor mode accepts the portfolio name
and back link, with public questions as suggestions. They receive callbacks and do not fetch
or save data. Styles use shared semantic, spacing, elevation and radius tokens.

The former studio, home, reviews, portfolio, platform and chat feature directories are removed; reusable logic lives in this package or `@shared/lib`.
